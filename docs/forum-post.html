OC COMMAND CENTRE – v4.0.0
The all-in-one organized crime toolkit for factions

 

Every member gets CPR colours, a status bar and smart Join blocking on the crimes page. Leaders get a live OC dashboard, reports, item costs and OC BREACH alerts, and can push CPR rules to the whole faction with a single newsletter.

No faction's rules are built in, so it works for any faction in Torn.

 

FOR EVERY MEMBER (NO API KEY NEEDED)

• CPR colours on every role: green = you qualify, red = too low, orange = too high. Missing items and wrong-CPR members are highlighted too.
• A status bar on every OC: OK TO JOIN / WAIT / START NEW / YOUR OC / DO NOT JOIN, a colour-coded stall timer and LAST JOIN.
• Join buttons that tell you why they're greyed out, e.g. "Needs 73 · you have 70" or "Hidden crime".
• Hidden crimes: OCs your faction doesn't run are removed from the list.
• Role weights from Torn Probability.
• Rules update themselves: open your faction's newsletter and the new CPR rules import instantly, with a "What changed" summary and Undo.

FOR LEADERS (FACTION API ACCESS)

• Live overview: who's not in an OC, open slots, what needs attention, missing items, members in hospital or travelling, possible early joins, with Mail and Hide buttons.
• Estimated success on every crime, even ones still recruiting (optional).
• OC BREACH alerts anywhere in Torn: wrong CPR, a hidden crime joined, or a missing item / unavailable member on an OC starting within the hour.
• Reports for any period: completed OCs, participation, item costs and an activity log, with CSV exports.
• CPR settings editor: per-role minimums and maximums, "no max in the last 48h", hidden crimes and an optional joining policy.
• One click generates a settings code and a ready-to-send faction newsletter.

SCRIPTING RULES

OC Command Centre only uses the Torn API and the page you're viewing. It never clicks, joins, leaves or submits anything for you, and makes no non-API requests to Torn. Only API calls run on a timer. A greyed-out Join button simply stops your own click, so no request is sent.

 

IS THE NEWSLETTER AUTO-IMPORT ALLOWED?

Yes. It only does what you could do by hand, and follows the rule of "the API or a page you have loaded manually and are currently viewing".

• It only reads a newsletter you open. It never opens, fetches or scans your mailbox or any other mail.
• It makes no requests at all, to Torn or anywhere else. It copies the settings code from the text on your screen, exactly like pasting it into the Import box yourself.
• Nothing leaves your device. Only the settings code is used; the rest of the mail, the sender and your other messages are never stored or sent.
• It doesn't act on Torn. Imported rules only change how the crimes page looks for you.
• Only genuine faction newsletters are trusted. Torn's own "This is a newsletter from your faction:" line is required, and it can't be typed into an ordinary mail.
• You stay in control. Every import shows "What changed" with Undo, and you can remove the rules at any time.

 

API KEY

• Regular members do not need a key.
• Leaders: Minimal key (or custom: faction basic, members, crimes; torn items) from a position with Faction API access.
• The key is stored only in your userscript manager and sent only to api.torn.com.

 

TERMS OF SERVICE

• Data Storage: Only locally (userscript manager / your browser). Nothing is stored elsewhere.
• Data Sharing: Nobody. Role weights are downloaded from tornprobability.com without sending anything about you. Optional, off by default: if a leader turns on Estimated success, OC names and slot pass rates are sent to tornprobability.com.
• Purpose of Use: Non-malicious statistical analysis / public community tools (faction OC management and item cost audit).
• Key Storage & Sharing: Stored / used only for automation (live refresh and breach checks). Kept locally, sent only to api.torn.com.
• Key Access Level: Custom – Minimal with Faction API access (faction basic, members, crimes; torn items).
