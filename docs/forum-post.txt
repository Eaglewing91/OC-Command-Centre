TITLE: [Script + PDA] OC Command Centre – CPR rules, Join blocking, live OC dashboard & breach alerts

OC COMMAND CENTRE  –  v4.3.1
The all-in-one organized crime toolkit for factions, built for any faction in Torn.

Every member gets CPR colours, a status bar and smart Join blocking on the crimes page. Leaders get a live OC dashboard, reports, item costs and OC BREACH alerts, and can push CPR rules to the whole faction with a single newsletter. No faction's rules are built in.


FOR EVERY MEMBER (no API key needed)
• CPR colours on every role: green = you qualify, red = too low, orange = too high. Missing items and wrong-CPR members are highlighted too.
• A status bar on every OC: OK TO JOIN / WAIT / START NEW / YOUR OC / DO NOT JOIN, a colour-coded stall timer, and LAST JOIN.
• Join buttons that tell you WHY they're greyed out, e.g. "Needs 73 · you have 70" or "Hidden crime".
• Crimes your faction doesn't run are hidden from the list.
• Role weights from Torn Probability.
• Rules update themselves: open your faction's newsletter and the new CPR rules import instantly, with a "What changed" summary and Undo.

FOR LEADERS (Faction API access)
• Live overview: who's not in an OC, open slots, what needs attention, missing items, members in hospital or travelling, possible early joins. Mail and Hide buttons on every free member.
• Estimated success on every crime, even ones still recruiting (optional).
• OC BREACH alerts anywhere in Torn: wrong CPR, a hidden crime joined, or a missing item / unavailable member on an OC starting within the hour.
• Reports for any period: completed OCs, participation, item costs and an activity log, with CSV exports.
• CPR settings editor: per-role minimums and maximums, "no max in the last 48h", hidden crimes and an optional joining policy.
• One click generates a settings code and a ready-to-send faction newsletter.

SCRIPTING RULES
Only uses the Torn API and the page you're viewing. It never clicks, joins, leaves or submits anything for you, and makes no non-API requests to Torn. Only API calls run on a timer. A greyed-out Join button simply stops your own click, so no request is sent.


ABOUT THE NEWSLETTER AUTO-IMPORT (is it allowed?)
Yes. It only does what you could do by hand, and it follows the scripting rule of "the API or a page you have loaded manually and are currently viewing":

• It only reads a newsletter YOU open. The script never opens, loads, fetches or scans your mailbox or any other mail. When you open a faction newsletter yourself on the Messages page, it reads that one mail, which is already on your screen.
• It makes no requests at all. There is no API call and no page request to Torn or anywhere else. It copies the settings code from the text in front of you, exactly as if you had copied and pasted it into the script's Import box.
• Nothing leaves your device. Only the settings code is used, plus the sender's name and player ID for the "imported from…" line, kept locally. The rest of the mail and your other messages are never stored, read further or sent anywhere. The imported CPR rules are saved only in your own userscript manager.
• It doesn't act on Torn. Importing rules only changes how the crimes page looks for you (colours, labels, greyed-out Join buttons). It never clicks, joins or submits anything.
• Only genuine faction newsletters are trusted. The script checks for Torn's own "This is a newsletter from your faction:" line, which can't be typed into an ordinary mail, so random mails can't change your rules.
• You stay in control. Every import shows a "What changed" notice with an Undo button, and you can remove the rules at any time in the member menu.

In short: you open the newsletter, and the script reads the code on the page you're looking at. It's the automatic version of copy and paste, with no extra requests.


API KEY
Regular members do NOT need a key.
Leaders: Minimal key (or custom: faction basic, members, crimes, positions; user basic, faction; torn items) from a position with Faction API access and Organised Crimes (or Leader / Co-leader). The key is stored only in your userscript manager and sent only to api.torn.com.


TERMS OF SERVICE
Data Storage: Only locally (userscript manager / your browser). Nothing is stored elsewhere.
Data Sharing: Nobody. Role weights are downloaded from tornprobability.com without sending anything about you. Optional, off by default: if a leader turns on Estimated success, OC names and slot pass rates are sent to tornprobability.com.
Purpose of Use: Non-malicious statistical analysis / public community tools (faction OC management and item cost audit).
Key Storage & Sharing: Stored / used only for automation (live refresh and breach checks). Kept locally, sent only to api.torn.com.
Key Access Level: Custom – Minimal with Faction API access (faction basic, members, crimes, positions; user basic, faction; torn items).
