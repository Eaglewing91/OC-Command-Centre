<p align="center" style="text-align:center"><b><span style="font-size:20px">OC COMMAND CENTRE</span></b><br><i>The all-in-one organized crime toolkit for factions · v4.0.2</i></p>
<p>&nbsp;</p>
<p align="center" style="text-align:center">Every member gets <b>CPR colours, a status bar and smart Join blocking</b> on the crimes page.<br>Leaders get a <b>live OC dashboard, reports, item costs and OC BREACH alerts</b>,<br>and can push CPR rules to the whole faction with a single newsletter.</p>
<p>&nbsp;</p>
<p align="center" style="text-align:center">No faction's rules are built in, so it works for <b>any faction in Torn</b>.</p>
<p>&nbsp;</p>
<p>&nbsp;</p>
<p align="center" style="text-align:center"><b><u>FOR EVERY MEMBER</u></b></p>
<p align="center" style="text-align:center"><i>No API key needed</i></p>
<p>&nbsp;</p>
<p>• <b>CPR colours on every role:</b> green = you qualify, red = too low, orange = too high. Missing items and wrong-CPR members are highlighted too.<br>• <b>A status bar on every OC:</b> OK TO JOIN / WAIT / START NEW / YOUR OC / DO NOT JOIN, a colour-coded stall timer and LAST JOIN.<br>• <b>Join buttons that tell you why</b> they're greyed out, e.g. "Needs 73 · you have 70" or "Hidden crime".<br>• <b>Hidden crimes:</b> OCs your faction doesn't run are removed from the list.<br>• <b>Role weights</b> from Torn Probability.<br>• <b>Rules update themselves:</b> open your faction's newsletter and the new CPR rules import instantly, with a "What changed" summary and Undo.</p>

<p align="center" style="text-align:center"><b><u>FOR LEADERS</u></b></p>
<p align="center" style="text-align:center"><i>Faction API access</i></p>
<p>&nbsp;</p>
<p>• <b>Live overview:</b> who's not in an OC, open slots, what needs attention, missing items, members in hospital or travelling, possible early joins, with Mail and Hide buttons.<br>• <b>Estimated success</b> on every crime, even ones still recruiting (optional).<br>• <b>OC BREACH alerts</b> anywhere in Torn: wrong CPR, a hidden crime joined, or a missing item / unavailable member on an OC starting within the hour.<br>• <b>Reports</b> for any period: completed OCs, participation, item costs and an activity log, with CSV exports.<br>• <b>CPR settings editor:</b> per-role minimums and maximums, "no max in the last 48h", hidden crimes and an optional joining policy.<br>• <b>One click</b> generates a settings code and a ready-to-send faction newsletter.</p>

<p align="center" style="text-align:center"><b><u>SCRIPTING RULES</u></b></p>
<p>&nbsp;</p>
<p align="center" style="text-align:center">OC Command Centre only uses the <b>Torn API</b> and the <b>page you're viewing</b>.<br>It never clicks, joins, leaves or submits anything for you, and makes no non-API requests to Torn.<br>Only API calls run on a timer. A greyed-out Join button simply stops your own click, so no request is sent.</p>
<p>&nbsp;</p>
<p>&nbsp;</p>
<p align="center" style="text-align:center"><b><u>IS THE NEWSLETTER AUTO-IMPORT ALLOWED?</u></b></p>
<p>&nbsp;</p>
<p align="center" style="text-align:center"><b>Yes.</b> It only does what you could do by hand, and follows the rule of<br><i>"the API or a page you have loaded manually and are currently viewing"</i>.</p>
<p>&nbsp;</p>
<p>• <b>It only reads a newsletter you open.</b> It never opens, fetches or scans your mailbox or any other mail.<br>• <b>It makes no requests at all,</b> to Torn or anywhere else. It copies the settings code from the text on your screen, exactly like pasting it into the Import box yourself.<br>• <b>Nothing leaves your device.</b> Only the settings code is used; the rest of the mail, the sender and your other messages are never stored or sent.<br>• <b>It doesn't act on Torn.</b> Imported rules only change how the crimes page looks for you.<br>• <b>Only genuine faction newsletters are trusted.</b> Torn's own "This is a newsletter from your faction:" line is required, and it can't be typed into an ordinary mail.<br>• <b>You stay in control.</b> Every import shows "What changed" with Undo, and you can remove the rules at any time.</p>
